### Photoacoustic Music Box

The goal is to use LED light to produce sound via the photoacoustic effect

I have plenty of ideas, but the current plan is:

1. Build a circuit to switch a high watt LED on and off very fast, then do some quick testing to see if photoacoustic actually work
2. Build a test enclosure.
3. Use a Pi Pico to control the LED driver
4. Play a continuous tone and iterate on the enclosure until it sounds clear
